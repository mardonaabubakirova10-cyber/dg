# План разработки проекта Digital Курсы с RAG-ассистентом на базе Google Drive / Excel / Word

## Архитектура без классической БД
- **Источник данных каталога (Курсы, Преподаватели, Цены, Скидки):** файл таблицы Excel (`.xlsx`), синхронизируемый с Google Drive / локальной папкой. При добавлении или удалении строк в Excel каталог на сайте динамически обновляется.
- **База знаний для RAG-ассистента:** документы Word (`.docx`), текстовые файлы и регламенты из Google Drive / локальной папки.
- **ИИ-модель:** Google Gemini API для генерации ответов и эмбеддингов по извлеченному контексту.
